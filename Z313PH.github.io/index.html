06 / PROJECT Reinforcement learning

AI research · Traffic control

CO₂-Aware Traffic Signal Control (DQN)

A reinforcement-learning controller for a 4-way intersection in the SUMO simulator. It learns signal timing that minimizes a CO₂-weighted cost while also penalizing delay, queues and excessive phase switching.

  • Custom SUMO/TraCI environment with a PyTorch Deep Q-Network agent
  • Benchmarked against fixed-time and actuated (queue-based) baseline controllers
  • Reproducible training and evaluation scripts, a smoke test, and CSV evaluation logs
